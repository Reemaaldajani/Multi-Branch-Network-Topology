# Multi-Branch Network Topology

A university networking project designed and simulated using **Cisco Packet Tracer**.

### Network Overview
- 4 Cisco 1841 Routers
- 3 Cisco 2960 Switches
- 6 End Devices (PCs)
- 3 LAN Networks
- WAN connections between the central router and branch routers

### Key Features
- Network topology design and configuration.
- IP addressing and device configuration.
- LAN connectivity testing.
- Inter-LAN communication testing.
- Network documentation and screenshots.

### Project Files
- `.pkt` – Packet Tracer project file.
- `Network-Topology.png` – Network topology diagram.
- `Screenshots/` – Configuration and connectivity test evidence.

**Tools:** Cisco Packet Tracer

**Project Type:** University Project
